# Design System Foundation

## Colors

- Primary blue: `#0057d9`
- Royal purple: `#7a1fd1`
- Orange accent: `#ff8a1d`
- White: `#ffffff`
- Dark gray: `#1f2937`
- Background light: `#f8fafc`
- Border color: `#d7dde8`
- Success: `#16a34a`
- Warning: `#f59e0b`
- Error: `#dc2626`

## Breakpoints

- Mobile: `30rem`
- Tablet: `48rem`
- Laptop: `64rem`
- Desktop: `80rem`
- Ultra wide: `96rem`

## Typography

Inter is loaded through `next/font/google` and assigned to the global font token.

## Spacing

Use an 8px grid for layout, section spacing, and component spacing.

## Motion

Motion should remain subtle and professional:

- Fade
- Slide
- Scale
- Hover
- Smooth scroll
- Lazy appearance
- Skeleton loading
