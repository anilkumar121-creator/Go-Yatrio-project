# Branding

GoYatrio uses the original provided PNG assets.

## Asset Paths

- Full logo: `apps/web/public/brand/goyatrio-logo.png`
- Mark: `apps/web/public/brand/goyatrio-mark.png`
- Favicon: `apps/web/public/favicons/favicon.png`

## Usage

Use the full logo for broad brand surfaces such as navbar, Open Graph, email headers, and footer contexts where horizontal space allows.

Use the mark for favicon, compact loading states, small admin shell surfaces, and icon-style placements.

Do not redraw, recolor, crop, or recreate the logo. Use the source PNG files unchanged.
